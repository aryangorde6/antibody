# Antibody

**Do your fixed bugs stay fixed?**

Antibody puts a project's past bug fixes back, one at a time, on today's code, and runs the project's
own tests. If every test still passes with a fix taken out, nothing stops that bug from coming back.

Work in progress: being built with IBM Bob during the IBM Bob 2.0 Hackathon, 25–27 September 2026.
